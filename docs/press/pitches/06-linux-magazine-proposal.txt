Subject: Proposal: build a private family photo server on a Raspberry Pi 5

Hello,

I'd like to propose a hands-on article, "Off the cloud: a family photo server on a Raspberry Pi 5" (about three pages). Readers build a home server that replaces Google Photos: phones back up in full resolution, tagging and face recognition run on the Pi, and the files are encrypted at rest on two microSD cards or USB disks mirrored as RAID 1. It uses Off The Cloud, a free software project (AGPL-3.0) I develop.

Outline:
1. Parts: a Pi 5, cards or disks, readers, and two optional status LEDs.
2. Flashing the signed image and setting it up over Bluetooth, or the install script on any Debian/Ubuntu machine.
3. Wiring the status lights to the GPIO, and what mdadm's states look like on them.
4. How the on-device AI works: RAM++ for tags, YuNet and SFace for faces.
5. Encryption at rest: Argon2id and AES-GCM, and why there is no password reset.
6. Remote access through a relay that can be self-hosted, or Tailscale Funnel.
7. Backing up the backup: rotating a mirror disk off-site.
