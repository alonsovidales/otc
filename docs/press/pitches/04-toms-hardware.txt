Subject: Open-source Raspberry Pi 5 photo server replaces Google Photos, with Android and Mac apps

Hi,

Off The Cloud turns a Raspberry Pi 5 into a home server for a family's photos and files. It's an open-source alternative to Google Photos and iCloud that keeps everything in the house:

- phones back up in full resolution;
- tagging and face recognition run on the Pi itself;
- files are encrypted at rest on two microSD cards (or USB disks) mirrored as RAID 1, with GPIO status lights for each one.

Setup takes no terminal: the desktop app writes the image and the Pi is configured over Bluetooth. The Android app is on Google Play, the Mac app on the Mac App Store, Windows and Linux apps are on the site, and the iPhone app is in App Store review. Remote access goes through an optional, self-hostable relay.

You can try it in a browser without installing anything: https://demo.off-the.cloud (a made-up family's library, read-only).

Code (AGPL): https://github.com/alonsovidales/otc
Site: https://off-the.cloud
