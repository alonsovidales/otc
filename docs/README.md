# Documentation

How Off The Cloud works, beyond the [main README](../README.md) (what it is, installing it,
configuration) and [CONTRIBUTING.md](../CONTRIBUTING.md).

| Document | What it covers |
|---|---|
| [`docker.md`](docker.md) | Off The Cloud on a Linux home server, NAS or Docker host (beta): installing, the owner password, connecting, updating, backup and restore. On a Raspberry Pi, use the image instead. |
| [`i18n.md`](i18n.md) | Localization: the seven languages, where a user's choice is stored, how the device, apps, website and emails render text, and how translations are generated and checked. The contributor guide is [`i18n/README.md`](../i18n/README.md). |
| [`bridge-capacity.md`](bridge-capacity.md) | What one bridge node can handle (connections, relayed messages, transfers), and how it was measured. The bridge cluster itself is described in [`bridge/cluster/README.md`](../bridge/cluster/README.md). |
| [`demo-device.md`](demo-device.md) | The public demo at demo.off-the.cloud: what demo mode refuses, and how to set up and update a demo device. [`demo-device/content/`](demo-device/content/README.md) has the scripts that made its sample library. |
| [`press/`](press/README.md) | The press kit: fact sheet, screenshots and the device photo. |
| [`promo/`](promo/README.md) | Marketing images (AI-generated scenes with the real app on screen) and the tools that compose them. |
| [`screenshots/`](screenshots) | Screenshots of the web and iPhone apps. |
| [`app-store/`](app-store), [`play-store/`](play-store) | The App Store and Google Play screenshots and graphics. |
